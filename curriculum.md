# Agentic Engineering — the course

A hands-on course for engineers who can already write code and want to make coding agents their **default way of working** — not an occasional autocomplete in the editor.

You don't learn this by reading. You learn it by building. Early on you pick one small, real project, and you carry it through every lesson — installing one new skill on it each time. By the end you have a finished, shipped project and the working habits of an agentic engineer.

## How the course works

- **16 lessons, 4 parts.** Each lesson is short to read and longer to do. Take them in order — each one builds on the last.
- **One project, the whole way.** You choose it in Lesson 5. Every lesson after that applies the new feature or concept to *your* project.
- **Every lesson ends with an exercise** that has a clear "done when." The exercise is the point — reading without doing changes nothing.
- **Claude Code is the tool we teach.** Codex CLI and Gemini CLI work the same way at the level that matters; we flag the differences where they count.

## What you'll have at the end

- A real project, built and shipped with an agent — not a tutorial toy.
- The scaffolding installed and used on it: a `CLAUDE.md`, a `DESIGN.md`, an eval suite, a no-slop review pass.
- The habits: briefs before code, evals before "done," parallel work when it's independent, proof before "shipped."

## The artifacts

Three forkable starters back the course. You install each one during its lesson:

- [`no-slop-skill/`](no-slop-skill/) — a review pass the agent runs against its own output (Lesson 12).
- [`templates/DESIGN.md`](templates/DESIGN.md) — a design-quality spec for anything with a surface (Lesson 13).
- [`second-brain-starter/`](second-brain-starter/) — a `CLAUDE.md` skeleton and memory structure (Lesson 11).
