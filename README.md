# Agentic Engineering — the course

A hands-on course for engineers who can write code and want coding agents to become **how they work**.

Pick one small, real project and build it to shipped, adding one new skill each lesson. Finish with a real project and the habits of an agentic engineer.

**Read it as a site:** [aisoftllc.github.io/agentic-engineering-curriculum](https://aisoftllc.github.io/agentic-engineering-curriculum/)

**Prefer a room:** [Agentic Engineering Day](https://aisoft.us/workshop) is the in-person workshop version: one shared lab, live review, and a first-week rollout plan.

## Start here

**Pick the entry point that fits you.** Coming in cold on AI? Start with **[Lesson 0.1 · the AI map](course/00a-the-ai-map.html)** — 30 minutes to a clean mental model. Already comfortable with the AI stack? Jump straight to **[Lesson 1 · what is agentic engineering](course/01-what-is-agentic-engineering.html)** and start building. Want the full path? Open **[the course index](curriculum.html)**.

32 lessons across 6 parts. Take them at the pace that works for you — a few evenings a week is fine. There's also a [Two-week FDE ramp](course/TWO_WEEK_FDE_RAMP.html) if you want a structured day-by-day plan toward Forward Deployed Engineer work, with the same lessons applied at depth.

- **Part 0 · Foundations** — the conceptual stack you walk in with: the four-layer AI map, LLMs just enough to be dangerous, what makes an agent, multimodality, the model zoo.
- **Part 1 · Get set up** — from nothing installed to your first agent session.
- **Part 2 · Build something real** — pick a project, take it all the way to shipped.
- **Part 3 · The core concepts** — the discipline that makes agent work hold up.
- **Part 4 · Scale up** — from one agent to a way of working.
- **Part 5 · Operating in the real world** — the harness wars, the application taxonomy, multi-agent + multi-human coordination, the intel-watch pattern, the team-shape playbook, and the failure modes in every layer.

Every lesson is short to read, longer to do, and ends with an exercise on your own project.

## Who it's for

Engineers who can write code and want agents to become how they work. The widest sweet spot is **senior full-stack engineers from any background** — mobile, infra, frontend, backend, data eng, platform. You've shipped real software. You may not have built with agents yet. The course meets you there.

Fresh graduates can follow it too — keep the project tiny and read every diff. Experienced engineers can move faster through setup, then take their time on the parts that are new. Part 5 in particular is the bridge from "I can ship with agents" to "I can ship into a customer's stack as a Forward Deployed Engineer," if that's the direction you want to go.

We teach Claude Code as the main path; Codex CLI, Gemini CLI, and Snowflake Coco are covered as variants where the workflow changes.
