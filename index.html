Learn agentic engineering by building.

Most engineers use coding agents like a fancier autocomplete. This course is the path to using them as your default way of working — learned the only way it sticks: by building one real project, start to finish, installing one new skill each lesson.

It’s for engineers who can already write code and have used AI in the editor once or twice. You start from nothing installed. You finish with a shipped project and the working habits to keep going. The open course is self-paced; the live workshop is for teams who want the room, the review, and the push.

Same tools — different discipline

Vibe coding

Prompt. Glance. Accept. Move on.

  • No plan — the goal lives only in your head
  • No check — “done” means it ran once
  • Review is a vibe check, if it happens at all
  • Fine for experiments — falls apart on real users

Quick, and quick to collapse.

Agentic engineering

Brief. Plan. Build. Gate.

  • Briefs are contracts — goal, constraints, done
  • You decide how you’ll know it worked, up front
  • Output is held to a standard the agent reads
  • Survives real users — because it was built to

Same agent. Not the same output.

How it works

One project, the whole way through. You pick it in Lesson 5 and carry it to shipped. Every lesson after that puts the new skill to work on your project — the exercise isn’t a quiz, it’s the next commit.

Every lesson ends with an exercise and a plain “you’re done when.” Reading without doing won’t move you — the doing is the lesson.

Claude Code is the main path. Codex CLI, Gemini CLI, and Snowflake Coco follow the same habits; the course flags the differences when they matter.
